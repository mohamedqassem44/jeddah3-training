# تطبيق تدريب صيادلة جدة 3 — نسخة 2.1

تطبيق ويب (PWA) بيتثبّت على أندرويد وآيفون. مدير المنصة: Dr. Qassem.

- index.html — التطبيق كله (الدخول، شاشات المتدرب، شاشات المدير والمدرب).
- manifest.webmanifest + icons — اسم التطبيق وأيقونته على الشاشة الرئيسية.
- sw.js — بيخلّي التطبيق يفتح من غير نت بآخر بيانات اتحمّلت.

التحديث: ارفع index.html الجديد مكان القديم (Add file ← Upload files ← Commit). التطبيق على الموبايلات بيتحدث لوحده أول ما يتفتح والنت شغّال.
